Does a tool improve the same agent?

The model, task and source stay fixed. We change the repository evidence available to the agent, then measure complete supported impact.

The prepared model is openai-codex/gpt-5.6-terra, with thinking off. Remote model weights have no independently available immutable digest; that limitation is explicit. Product, index, task, harness, SDK and configuration identities are retained.

How a product-assisted attempt works

  1. A fixed native playbook gathers product candidates from the public patch and question.
  2. The agent receives those results and checks them with read-only source tools. Follow-up product calls are bounded.
  3. It reports repository behavior, obligations, symbols, directed contracts and repair actions.
  4. An independent scorer checks those claims against the frozen runtime evidence.

The treatment is the agent plus the product and fixed playbook, rather than an isolated graph algorithm. The public task prompt must be identical across all four arms. Effective prompts differ because native product outputs differ; trusted receipts retain the exact evidence each agent saw.

What is held constant

The same ten repositories, complete upstream patch, public compatibility policy, model, SDK, scorer and per-attempt ceilings apply to every arm. The origin diff is assumed applied; merely implementing it is not downstream remediation. Expected consumers, repair counts and causal chains are not supplied in the question.

Each case has three independent sessions per arm. Case order is seeded and starting-arm order rotates across repetitions. Native setup and index identity are checked before provider initialization.

How we will decide

The primary question is whether a product increases the rate of complete supported impact. We average the three repetitions within each case, then weight the twelve cases equally. Paired wins, losses, ties, failures, unsupported claims and cost remain visible.

The frozen practical-benefit rule requires a complete balanced campaign, a gain of at least 10 percentage points, a positive lower interval bound and no observed compatible-control safety regression. We report case-cluster intervals and six-family sensitivity; repetitions are not independent cases, and the three product comparisons remain exploratory.
