Worked discriminator: REST-001

Rename Account's address field from postalCode to postcode. Order silently binds a null value and publishes it through an unchanged Kafka event. Shipment then rejects the value and sends the event to its dead-letter queue. Static key matching misses the transitive failure; naive text matching reports the pass-through BFF incorrectly.
