Run the worked example

The harness uses only Python's standard library. No package installation is required.

1. Check the scorer

cd impact-study/harness
python3 -m unittest discover -s scoring -p 'test*.py'

This runs 15 fast tests for matching, scoring, severity, validation, and aggregation.

2. Score the agent-only answer

python3 scoring/score.py score +  --ground-truth records/REST-001.json +  --answer answers/examples/REST-001-agent-only.json

The report shows what the agent found, what it missed, and which extra repositories were false positives.

3. Ask what Gortex added

python3 scoring/score.py marginal +  --ground-truth records/REST-001.json +  --baseline answers/examples/REST-001-agent-only.json +  --candidate answers/examples/REST-001-gortex.json

For REST-001, the worked Gortex answer adds three correct findings over the agent baseline, including the critical Shipment dependency, and one false positive.

Optional: run an agent blind

The runner gives Claude or Codex the estate and the change question without exposing the frozen answer.

python3 run/run.py --help

Optional: start the e-commerce fixture

docker compose -f commerce-platform/compose.yaml up --build -d

Open the storefront at http://localhost:3000 or the BFF API documentation at http://localhost:8080/swagger-ui.html.

docker compose -f commerce-platform/compose.yaml down
