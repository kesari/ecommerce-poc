Run the study

Score a frozen scenario, measure what a candidate adds over a baseline, or run an agent blindly against a clean copy of the estate.

Verify the harness

The scoring harness uses only Python's standard library.

cd impact-study/harness
python3 -m unittest discover -s scoring -p 'test*.py'

Score one answer

python3 scoring/score.py score +  --ground-truth records/REST-001.json +  --answer answers/examples/REST-001-agent-only.json

The report includes cross-repository, contract, symbol, and test recall; precision; evidence quality; miss severity; provenance distribution; and the weighted composite.

Measure marginal graph value

python3 scoring/score.py marginal +  --ground-truth records/REST-001.json +  --baseline answers/examples/REST-001-agent-only.json +  --candidate answers/examples/REST-001-gortex.json

This asks the central POC question directly: what correct impact did the candidate find that the simpler baseline did not?

Run a blind agent baseline

The runner creates a clean estate copy, excludes frozen ground truth and contestant answers, renders the same prompt, and invokes a configured read-only contestant.

cd impact-study/harness
python3 run/run.py --help

Claude and Codex agent-only commands are configured in run/contestants.json. Generated answers should be validated and scored without exposing the ground truth during execution.

Start the fixture estate

Docker Compose is optional for scoring but useful for active-change simulations and end-to-end verification.
