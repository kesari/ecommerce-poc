Run locally

Docker Compose is the shortest path to the complete browser-to-events workflow.

Full estate

Install Docker Desktop with Compose, clone the repository, and run:

docker compose -f commerce-platform/compose.yaml up --build -d

Open the storefront at http://localhost:3000. The BFF API documentation is at http://localhost:8080/swagger-ui.html.

docker compose -f commerce-platform/compose.yaml ps
docker compose -f commerce-platform/compose.yaml logs -f commerce-bff
docker compose -f commerce-platform/compose.yaml down

Developer checks

Java services require Java 21 and use the Maven Wrapper:

cd account-service
./mvnw verify

The React application requires Node.js 22:

cd commerce-web
npm ci
npm run lint
npm test
npm run build

Observability

Jaeger is available on port 16686 and Prometheus on 9090. Service health and metrics use Spring Boot Actuator.

Local data

PostgreSQL, Kafka, Valkey, and Prometheus use named Docker volumes. Add -v to the Compose down command only when you intend to erase them.

Security note

Database passwords and the JWT secret in Compose are development fixtures. Use injected secrets and secure infrastructure outside this POC.
